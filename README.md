# 아이들 스쿨 (idddle) — 방치형 학교 키우기

빌드 도구 없이 HTML/CSS/JS만으로 돌아가는 방치형 클리커 게임입니다.
교과서를 눌러 **지식**을 모으고, 연필·학생·선생님·도서관… 을 들여 학교를 키웁니다.
`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 기능
- 교과서 클릭으로 지식 획득 (누를 때마다 책장이 넘어감)
- **우리 학교 (교실 풍경)**: 생산기를 살 때마다 그 교실에 일꾼이 한 명씩 늘고, 업그레이드를 사면 교실에 물건이 놓임
  - 일꾼마다 일하는 동작이 다르고(필기·끄덕·책장 넘기기·실험…), 업그레이드할수록 빨라짐
  - 머리 위로 작업 이모지(💡📢📄⚗️💾…)가 떠오르고, 교실 진행 막대가 찰 때마다 번 지식(+N)이 표시됨
  - 클릭 업그레이드는 왼쪽 **책상** 위에 놓임
- 생산기 10종 (연필 → 학생 → 선생님 → 도서관 → 과학실 → 컴퓨터실 → 대학교 → 인터넷 강의 → 우주 학교 → 타임머신 교실), x1 / x10 / x100 / MAX 구매
- 업그레이드 62종: 생산기마다 5단계(지우개, 책가방, 학생이 준 사과, AI 조교…) + 시너지 8종(예: 1:1 과외 = 선생님 수만큼 학생 생산 증가) + 클릭 4단계
- 상점의 생산기마다 다음 업그레이드가 열리기까지 남은 진행도 표시
- 📝 쪽지 시험: 2분 30초마다 산수 문제 (12초 제한, 맞힐수록 어려워지고 연속 정답일수록 보상 증가)
- 📅 출석부: 하루 한 번 접속 보상, 연속 출석일수만큼 커짐 (최대 7배)
- 🎒 학년: 누적 지식이 10배가 될 때마다 유치원 → 초등 1학년 → … → 인류의 스승으로 진급
- 칭찬 스티커: 1~2.5분마다 「참잘했어요」 도장이 나타남 → 지식 즉시 획득 / 집중 시간(생산 x7) / 필기 폭주(클릭 x15) / 교장선생님 선물(생산기 공짜)
- 업적 65개: 업적 1개당 전체 생산 +2%, 졸업해도 유지
- 졸업(환생): 진행을 초기화하고 졸업장 획득 → 졸업장 1장당 전체 생산 +10%
- 학교 발전 계획 11종: 졸업장으로 사는 영구 강화 (오프라인 효율·시간, 칭찬 스티커, 가격 할인 등)
- 오프라인 보상: 자리를 비운 시간만큼 생산 (기본 최대 8시간, 효율 50%)
- 자동 저장, 저장 내보내기/가져오기, 깨진 저장 데이터 자동 복구
- 설정: 숫자 표기(만·억·조 / K·M·B / 1e6), 효과음 켜기/끄기 (WebAudio 합성, 파일 없음)

## 구조
| 파일 | 역할 |
|---|---|
| `src/data.js` | 콘텐츠·밸런스 데이터 (생산기, 업그레이드 이름/아이콘, 업적, 발전 계획) — 조정은 여기서 |
| `src/engine.js` | 게임 상태/규칙/저장. DOM 없음 |
| `src/ui.js` | 화면 렌더링, 교실 풍경, 입력 처리, 게임 루프 |
| `src/style.css` | 스타일 (모두 `.idd` 아래로 한정) |
| `tests/engine.test.js` | 엔진 단위 테스트 — `npm test` (Node 18+, 의존성 없음). 배포 전에 CI에서도 실행 |

## 웹사이트에 넣기
```html
<link rel="stylesheet" href="src/style.css">
<div id="idle-game"></div>
<script src="src/data.js"></script>
<script src="src/engine.js"></script>
<script src="src/ui.js"></script>
<script>Idddle.mount(document.getElementById('idle-game'), { saveKey: 'idddle-school-v1' });</script>
```
CSS가 `.idd` 클래스 안으로 한정되어 있어 기존 사이트 스타일과 충돌하지 않습니다.
손글씨 폰트(Gaegu)와 Pretendard는 `index.html`처럼 따로 불러오면 적용되고, 없으면 시스템 폰트로 대체됩니다.

## 모바일
- 더블탭 확대 방지(`touch-action: manipulation`), 교과서는 손가락이 닿는 순간 반응해서 연타가 빠짐없이 인정됨
- `index.html`은 두 손가락 확대도 막음(게임 전용 페이지라서). 다른 사이트에 넣을 땐 게임 영역 안에서만 더블탭 확대가 막힘

## GitHub Pages 배포

## 디버깅
`index.html`에서는 콘솔에서 `game.state.light = 1e9` 같은 식으로 상태를 직접 바꿀 수 있습니다.
`game.spawnBonus()`로 칭찬 스티커를 바로 띄울 수 있습니다.
