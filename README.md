# 아이들 스쿨 (idddle) — 방치형 학교 키우기

빌드 도구 없이 HTML/CSS/JS만으로 돌아가는 방치형 클리커 게임입니다.
교과서를 눌러 **지식**을 모으고, 연필·학생·선생님·도서관… 을 들여 학교를 키웁니다.
`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

플레이: https://imkr3.github.io/idddle/

## 콘텐츠
- **교실(생산기) 14종**: 연필 → 학생 → 선생님 → 도서관 → 과학실 → 컴퓨터실 → 대학교 → 인터넷 강의 → 우주 학교 → 타임머신 교실 → 꿈속 학교 → 지식의 나무 → 평행우주 분교 → 진리의 전당
- **업그레이드 136종**: 교실마다 7단계, 시너지 18종, 클릭 8종, 급식 12종
- **우리 학교**: 교실을 살 때마다 일꾼이 늘고, 업그레이드를 사면 그 교실 선반(또는 책상·급식실)에 물건이 놓임
- **집중력과 아하!**: 쉬지 않고 누르면 클릭 지식이 최대 2배(계획으로 3배), 가끔 10배짜리 아하!
- **시간표**: 45초마다 교시가 바뀌며 해당 교실 생산 2배, 점심시간엔 클릭 3배
- **칭찬 스티커**: 지식 / 집중 시간 / 필기 폭주 / 교장선생님 선물 / 바자회 / 스티커 비
- **스티커 앨범 30종**: 일반·희귀·영웅·전설. 모을수록 생산 증가, 등급을 다 모으면 추가 보너스
- **쪽지 시험 6과목**: 산수(자동 생성) + 영어·맞춤법·세계 수도·과학·속담 문제 280여 개, 성적표
- **숙제 50개**: 다음 할 일을 알려 주는 길잡이, **출석부**, **학년 30단계**, **교내 방송** 50여 줄
- **졸업(환생)**: 졸업장 1장당 생산 +5%, **학교 발전 계획 31종**(자동 필기, 오프라인 강화, 반장 등)
- **도전 학기 7종**: 규칙이 걸린 학기를 통과하면 영구 보상
- **업적 155개**(숨겨진 업적 8개 포함)
- 오프라인 보상, 자동 저장, 저장 내보내기/가져오기, 숫자 표기·효과음·화면 효과 설정

## 구조
| 파일 | 역할 |
|---|---|
| `src/data.js` | 콘텐츠·밸런스 데이터 — 이름과 숫자는 여기서 고친다 |
| `src/quiz-data.js` | 쪽지 시험 문제 은행 |
| `src/engine.js` | 게임 상태·규칙·저장. DOM 없음 |
| `src/ui.js` | 화면 렌더링, 입력 처리, 게임 루프 |
| `src/style.css` | 스타일 (모두 `.idd` 아래로 한정) |
| `tests/` | 엔진 단위 테스트 — `npm test` (Node 18+, 의존성 없음) |
| `tools/sim.js` | 밸런스 시뮬레이터 — `npm run sim` |

## 밸런스
`tools/sim.js`가 가상 플레이어로 수십 시간을 몇 초 만에 돌려 봅니다.

```bash
npm run sim -- --profile active --hours 45
```

```bash
npm run sim -- --profile daily --days 40
```

현재 수치 기준(시뮬레이션 결과, 실제 사람 플레이와는 다를 수 있음):
- 자주 누르는 플레이어: 첫 졸업 약 40분, 마지막 교실 약 20시간, 도전 학기 전부 약 31시간
- 가끔 누르는 플레이어: 첫 졸업 약 55분, 마지막 교실 약 50시간
- 하루 3번 20분씩 접속: 마지막 교실 약 11일, 발전 계획 전부 약 16일
- 졸업은 졸업장이 지금의 40~50%쯤 더 모였을 때 하는 것이 가장 빠름

`data.js`의 숫자를 바꾸면 이 명령으로 흐름을 다시 확인하세요.

## 웹사이트에 넣기
```html
<link rel="stylesheet" href="src/style.css">
<div id="idle-game"></div>
<script src="src/data.js"></script>
<script src="src/quiz-data.js"></script>
<script src="src/engine.js"></script>
<script src="src/ui.js"></script>
<script>Idddle.mount(document.getElementById('idle-game'), { saveKey: 'idddle-school-v1' });</script>
```
CSS가 `.idd` 안으로 한정되어 기존 사이트 스타일과 충돌하지 않습니다.
손글씨 폰트(Gaegu)와 Pretendard는 `index.html`처럼 따로 불러오면 적용되고, 없으면 시스템 폰트로 대체됩니다.

## 모바일
- 더블탭 확대 방지, 교과서는 손가락이 닿는 순간 반응
- 업그레이드·발전 계획은 한 번 누르면 설명, 한 번 더 누르면 구매
- 좁은 화면에서는 숙제 카드와 교실이 가로로 넘어감

## 배포
`.github/workflows/pages.yml`이 푸시할 때마다 테스트를 돌린 뒤 GitHub Pages에 배포합니다.

콘솔에서 `game.state.light = 1e9`처럼 상태를 바꿀 수 있고, `game.spawnPraise()`로 칭찬 스티커를 바로 띄울 수 있습니다.
